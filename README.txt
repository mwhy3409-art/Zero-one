Zero one - install on Android

1. Upload this whole folder to any free HTTPS host:
   - Netlify Drop: go to app.netlify.com/drop and drag the folder in
   - or GitHub Pages / Cloudflare Pages / Vercel
2. Open the site address in Chrome on your Android phone.
3. Chrome menu (three dots) > Install app (or Add to Home screen).
4. Allow Location and Notifications when asked.

Want a real .apk file? Go to pwabuilder.com, paste your site address,
and choose Android to download a package.
